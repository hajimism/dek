Ⅲ　運用

始めかた

要るのは Bun だけ。プロジェクトを作り、台本を書き、開発サーバを立ち上げる。最初の 1 枚は骨格のままでいい。通しで喋れるようになってから、必要なスライドだけを仕上げる。

必要なもの

Bun 1.3+必須。dek は GitHub から直接動かす

Playwright描画の lint、スクリーンショット、PDF、動画

ffmpeg動画の書き出し

VOICEVOX音声合成。互換エンジンでもよい

足りないものがあっても、それを使うコマンドだけが止まり、入れ方を教えてくれる。

terminalドキュメント hajimism.github.io/dek# 1. プロジェクトと最初のデッキを作る
$ bunx github:hajimism/dek init my-talks --deck 2026-10-meetup
$ cd my-talks && bun add github:hajimism/dek
$ cd decks/2026-10-meetup

# 2. 台本を書く ── 時間はここに使う
$ $EDITOR script.md

# 3. 開発サーバ。保存のたびに骨格・再描画・lint
$ bunx dek

# 4. 配る
$ bunx dek build     # dist/2026-10-meetup.html
$ bunx dek pdf       # dist/2026-10-meetup.pdf
