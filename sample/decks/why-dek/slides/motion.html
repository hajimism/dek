動きは、時間の関数として書く

CSS で書けない動きは slides/<id>.ts に書きます。約束はひとつ。経過時間 t を受け取って、その瞬間の画面を描くこと。

slides/motion.ts抜粋const MS = 1200;

function paint(frame: Element, t: number) {
  // t だけから棒の高さを決める
  …
}

export default {
  motion: { "1": MS },
  draw(slide, { t }) {
    for (const frame of frames(slide)) {
      paint(frame, Number(frame.dataset.t));
    }
    const live = slide.querySelector("[data-live]");
    if (live) paint(live, t);
  },
} satisfies DekSlide;

同じ t を渡せば、必ず同じ画面になる

発表
t を 0 から 1200 まで、画面の更新ごとに進める。滑らかに動く。
PDF・スクリーンショット
最後の t で一度だけ描く。動き終わった姿が写る。
動画
t をコマごとに送る。実時間を待たず、正確に記録される。

左の三枚は data-t の値で、右端は再生中の t で、同じ paint() が描いている。
