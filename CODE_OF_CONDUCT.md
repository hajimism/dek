# Code of Conduct

dek adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in the repository, its issues and pull requests, and anywhere you represent the project.

In short: be considerate, assume good faith, and keep criticism about the work, not the person. Harassment, insults, and unwelcome personal attention are not acceptable.

## Reporting

Report conduct that breaks it to the maintainer, [@hajimism](https://github.com/hajimism), privately. Reports are kept confidential. The maintainer decides on the response, from a warning to a ban, following the Covenant's enforcement guidelines.
