# FAQ

## どうやって入れますか

`bunx dekc init` でプロジェクトを作り、その中で `bun add -d dekc` と入れてから `bunx dekc` を使います。手順は[はじめる](./getting-started)にあります。

## `bunx dek` で別のものが動きます

コマンドは `dek` ではなく `dekc` です。npm の `dek` は無関係の別パッケージで、`bunx dek` はそれをダウンロードして実行します。

## Slidev を使うべきなのはどんなときですか

ライブコーディング、スライド内の Vue コンポーネント、npm のテーマ、埋め込みエディタが必要なときです。dekc は喋りが中心のトークのためのもので、表に出すのは素の HTML と CSS だけです。比較は [dekc の設計思想](./why#他のツールとの違い)にあります。

## HTML を書かなければいけませんか

いいえ。`script.md` を書いて `dekc` を叩けば、同梱テーマの骨格スライドで発表できます。画面に台本以上のことを語らせたくなったときに、HTML を書き始めてください。

## 声は必須ですか

いいえ。`voice/` のないデッキも、あるデッキとまったく同じ理由で lint に落ちます。声は、オプトインしたデッキにだけ警告（`DEKC040`、`DEKC042`、`DEKC043`）を足します。`duration` と比べる `DEKC041` は、`duration` を書いたすべてのデッキが対象です。

## スライドのファイル名に番号がないのはなぜですか

順序を知っていてよいファイルは一つだけで、それは `script.md` です。番号付きのファイル名は並べ替えのたびにリネームが必要になり、差分が読みにくくなります。並べ替えは `dekc mv <slug> --before|--after <other>` で行います。

## `sync` は HTML を上書きしますか

一度でも手を入れたファイルは上書きしません。HTML のないスライドに骨格を作り、まだ誰も編集していない骨格はセクションが変われば書き直し、セクションが消えれば削除します。編集したファイルには触れず、セクションが消えていれば lint が孤児として報告します（`DEKC002`）。リネームもしません。改名は `dekc mv` です。

## エージェントは何を叩きますか

人間と同じ CLI です。`dekc help --agent`、`dekc check <slug> --shot`、`dekc lint --format sarif`。MCP サーバはありません。[AI エージェントと作る](./ai)を読んでください。

## 開発サーバなしで発表できますか

できます。`dekc build` が HTML を 1 ファイル作ります。USB メモリに入れてください。`p` を押すか `?presenter` を付けて開くと、別ウィンドウが `BroadcastChannel` で追従します。別のデバイスからデッキを操作したいときだけ `dekc --remote` を使います。

## Playwright、ffmpeg、VOICEVOX は必須ですか

いいえ。どれも任意で、足りないときはそれを必要とするコマンドだけが、インストール手順の hint 付きで失敗します。`--visual`、`shot`、`pdf`、`video` は Playwright を、`video` は加えて ffmpeg を、`voice`、`rehearse`、`video` は VOICEVOX 互換エンジンを使います。エンジンの入れ方は[声と動画](./voice#セットアップ)にあります。

## 間や無音の時間はどこに書きますか

台本には書きません。段落のないビートは遷移と設定された `pause.beat` を通過するだけです。デモの間に喋るなら、その言葉を台本に書いてください。書けば見積もりに数えられます。ナレーションで特定のビートやスライドのあとに長めの間を取りたいときは `voice/voice.toml` に書きます。[タイミング](./voice#タイミング)を参照してください。

## スライドで JavaScript は動かせますか

HTML の中では動かせません。そこに `<script>` を書くと `DEKC011` です。カウンタや自分で描かれていくグラフのように CSS で表せない動きは、`slides/<id>.ts` に時間の関数 `draw` として書きます。時計はランタイムが持つので、同じスクリプトがライブでは再生され、`dekc video` ではフレームごとにシークされ、`dekc shot` と PDF では最後の状態が写ります。クリックで動くデモは対象外です。[スクリプトで動かす](./steps#スクリプトで動かす)を参照してください。

## 1 枚だけの CSS はどこに書きますか

HTML の横の `slides/<id>.css` です。その枚にスコープされ、`max_classes` にも数えられません。[スライドごとの CSS](./slides#スライドごとの-css)を参照してください。
