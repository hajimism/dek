## 条件

- `DEK030` と `DEK031` は `--visual` のときだけ動き、Playwright が必要です。
- `DEK040`、`DEK042`、`DEK043` は `voice/` のあるデッキだけに適用されます。`dek cues` は `voice/` の有無に関わらず `DEK042` を報告します。
- `DEK041` は Timeline のあるデッキだけに適用されます。
- `DEK040` から `DEK043` は警告です。ライブ専用デッキの完成の定義は変わりません。

## 補足

### DEK001 / DEK002

`--fix` は骨格を作り、既存ファイルには触れません。それぞれちょうど 1 件なら改名を疑い、lint は `dek mv <old> <new>` を提案します。どちらかが 2 件以上あれば推測しません。

### DEK003

解決できない参照です。要素のないビートは問題なく、位置が連続している必要もありません。

### DEK005

`data-morph` の名前は同じ枚の中で一意でなければなりません。`view-transition-name` になるので、ブラウザは遷移の両側にちょうど 1 つずつの要素を必要とします。別々の枚に同じ名前を付けるのが本来の使い方です。

### DEK010

`theme.css` にそのクラスを定義すれば解消します。その枚でしか使わないなら `slides/<id>.css` に定義します。共有の語彙を増やすのは設計判断で、lint はそれを目に見える一手にします。`DEK013` がその一手の回数に上限を置きます。スライドのスタイルシートは数えません。

### DEK014 / DEK015

生の値は `--*` プロパティへの代入にだけ書けます。単位なしの `0`、`thin`、`em` は通ります。生のフォールバック付き `var()` は通りません。契約の 13 トークンはすべて `.slide` に公開する必要があります。追加のトークンは歓迎します。

### DEK020 / DEK021 / DEK022 / DEK023

自己完結の規約です。リモートも、プロジェクト直下も、隣のデッキも参照できません。ローカルの `src` は `assets/` で始めます。`dek build` が全アセットをインライン化でき、プロジェクト直下で立てた開発サーバがそれらを配信できるのは、この制約があるからです。

### DEK031

閾値は WCAG AA に従います。本文は 4.5:1、大きな文字は 3:1。大きな文字とは、計算後の `font-size` が 24px 以上、または 18.66px 以上で `font-weight` が 700 以上のものです。淡い色の大きな数字は通り、同じ色の本文は落ちます。閾値は変更できません。

### DEK042

喋りになるのは段落だけです。リスト、コード、表しかないビートは、ナレーションでは `pause.beat` ミリ秒で通過します。空のビートと引用だけのビートは意図的な間として扱い、警告しません。
