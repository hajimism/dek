# エージェント評価の記録

[English](./README.md)

ここにあるファイルは、それぞれエージェント評価の記録 1 回分です。エージェントが dek をどれだけうまく扱えるかを、リリースごとに比べるために残します。リリースの前後に、リリースするチェックアウトで次を実行します。

```bash
bun scripts/agent-eval.ts --runs 3 --record evals/agent/results
```

書き出されたファイル `<日付>-v<バージョン>.json` は、そのままコミットします。同じ日、同じバージョンの 2 回目以降は `-2`、`-3` と続き、先の記録を上書きしません。

記録には、シナリオごとに、実行・成功・スキップの回数、時間・`dekc` の実行回数・繰り返し・残った警告の中央値、そして全実行でヒントなしに dek が示したエラーの数が入ります。パス、トランスクリプト、エージェントが書いた文は入りません。それらは `.cache/agent-eval/` の完全なレポートに残ります。

1 回の実行は逸話にすぎません。1 度成功したエージェントが次は失敗することもあります。3 回以上の実行の記録を読み、同じエージェントで作った記録どうしを比べてください。記録にはエージェントの名前が入らないので、どのエージェントのどのバージョンかはコミットメッセージに書いてください。
